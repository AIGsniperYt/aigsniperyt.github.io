# Pixel Art Snipper

An image cropping / snipping tool designed for pixel art. Upload images, zoom in (up to 24×), select pixel regions via a drag-select box, and export the selection as a PNG.

**Features:**
- Up to 24× zoom with pixel-perfect rendering
- Snap-to-pixel-grid selection
- Configurable grid cell size, offset, and overlay grid
- Filename customisation and real-time dimension display

**Technologies:** HTML, CSS, Canvas 2D API, vanilla JavaScript
