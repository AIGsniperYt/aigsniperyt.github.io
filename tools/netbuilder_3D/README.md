# 3D Box Net Generator

A 3D box modelling tool. Set custom width, height, and depth; view the box in real-time 3D (Three.js); and generate a printable 2D folding net as SVG.

**Features:**
- Real-time 3D preview with auto-rotation
- Generates a 6-face folding net as SVG with correct face layout
- SVG export and download

**Technologies:** HTML, CSS, Three.js (CDN), SVG, vanilla JavaScript
