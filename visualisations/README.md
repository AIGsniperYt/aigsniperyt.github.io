# **MAJOR** — Algorithm & Simulation Visualisations

A collection of interactive algorithm and simulation visualisations across nine sub-projects.

**Included visualisations:**
- **A\* Pathfinding** (`a-star/`) — Interactive grid-based pathfinding with v1, side.js, and zorg variants
- **Autonomous Car** (`autocar/`) — Self-driving car simulation
- **Cellular Automata** (`celllular automata/`) — Cave/dungeon generation with noise density controls
- **Ant Foraging** (`foraging/`) — Swarm intelligence simulation with pheromone trails
- **Perlin Noise** (`perlin noise/`) — 2D terrain generation
- **Pirate Ship** (`pirate/`) — 3D pirate ship scene with vertex-based water (Three.js)
- **Simplex Noise** (`simplex/`) — 3D terrain height maps (Three.js)
- **Algorithms** (`algorithms/`) — Sorting & searching visualiser (Bubble, Selection, Insertion, Quick Sort)
- **Raycasting** (`raycasting/`) — First-person raycasting visualisation from a 2D map - wolfenstein style

**Technologies:** Canvas 2D API, Three.js, vanilla JavaScript
