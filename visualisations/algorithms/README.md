# Sorting Algorithm Visualiser

Interactive visualisation of four sorting algorithms (Bubble Sort, Selection Sort, Insertion Sort, Quick Sort). Renders bars on a 2D canvas and animates swaps and comparisons in real time.

**Features:**
- Adjustable data size (10–200 bars) and animation speed (ms delay)
- Comparison and swap counters
- Random data regeneration

**Technologies:** HTML, CSS, Canvas 2D API, vanilla JavaScript
