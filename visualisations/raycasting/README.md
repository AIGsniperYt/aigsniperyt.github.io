# 3D Raycasting Engine

A Wolfenstein-3D-style raycasting engine that renders a first-person view from a 2D map. Move with WASD, rotate, and toggle ray visibility.

**Features:**
- Slider-adjustable FOV (field of view) and number of rays
- Fisheye effect correction via cosine-adjusted distances
- Toggleable ray visualisation
- Click to toggle walls

**Technologies:** HTML, CSS, Canvas 2D API, vanilla JavaScript
