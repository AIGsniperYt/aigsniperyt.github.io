# Communications Network Visualisation (Client)

A full-screen animated neural network / node visualisation with a gradient background, floating connected nodes, and a hidden text input. Nodes react to mouse movement and typing.

**Features:**
- Light/dark theme toggle with gradient backgrounds
- Proximity-based connecting lines between nodes
- Hidden textarea — typing creates visible drifting characters on screen
- Mouse-reactive node highlighting

**Technologies:** HTML, Canvas 2D API, vanilla JavaScript
