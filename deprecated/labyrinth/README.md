# Labyrinth — Python Maze Generation (Pygame)

A Pygame-based maze generation and exploration game using frontier-based (recursive-backtracker-style) algorithms.

**Files:**
- `game.py` — Fullscreen maze generator with JSON-based save/load for player state (health, position, inventory with weapons/health items/torches, dark level chance)
- `zombies.py` — Simple grid-based "Player Movement with Walls" demo with collision detection
- `game_data.json` — Persistent player save data
- `levels.json` — Level definitions

**Technologies:** Python, Pygame
