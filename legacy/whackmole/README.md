# Whack-a-Mole

**Status:** Active

A classic Whack-a-Mole game. Moles pop up randomly in a 3×3 grid of holes — click to "bonk" them and score points within a 10-second time limit.

**Features:**
- 3×3 grid with circular holes
- 10-second timed gameplay
- Score tracking with random mole intervals

**Technologies:** HTML, CSS, vanilla JavaScript (DOM-based)
