# 2D Camera System

**Status:** Active

A 2D camera demo where a blue triangle (player) moves with WASD across a large tile grid. The camera follows the player, rendering only visible tiles. The triangle rotates toward the mouse cursor.

**Features:**
- WASD camera panning
- World-to-screen coordinate transformation
- 120×100 tile grid with random coloured tiles
- Mouse-aiming with rotation

**Technologies:** HTML, Canvas 2D API, vanilla JavaScript
