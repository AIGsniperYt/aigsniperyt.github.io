# **MAJOR** — Simple Game V2

First full-featured game — a 2D top-down zombie shooter with multiple weapons, XP/leveling, powerups, and particle effects. 2036 lines of JavaScript.

**Features:**
- 5 weapons: Minigun (radial glow), Flamethrower (cone gradient), Poison Gun, Dual Pistol, Loki Pistol
- XP and leveling system that unlocks better weapons
- Powerups: shield, speed, energy
- Dash mechanic, particle effects, status bars with icons
- Fullscreen Canvas rendering
- Changelog documenting development from 1–6 May 2024

**Technologies:** HTML, Canvas 2D API, vanilla JavaScript
