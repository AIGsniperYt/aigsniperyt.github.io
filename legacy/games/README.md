# **MAJOR** — Games Collection

A collection of browser-based games with a "Split-Screen Project" game hub/launcher.

**Game Hub:** `index.html` and `menu.html` — Split-screen launcher with game descriptions, controls info, and direct links.

**Included games (launcher-listed):**
- **Plane Game** — 2-player dogfighting with guns and missiles
- **1v1** — 2-player side-view shooter (15 HP each)
- **Mining** — (In development) Resource mining with camera follow
- **Paint** — Browser-based MS Paint clone with toolbar
- **Alien (Galactic Guardian)** — Top-down alien shooter with WASD + mouse aim

**Standout titles:**
- **[Simple Game V2](simple%20games/simple%20game%20v2/)** — **MAJOR**: 2036-line zombie shooter with 5 weapons, XP system, powerups, and particles. The first full game.
- **Simple Game V1** — Earlier prototype
- **Simple Game V3** — Story-driven sequel

**Additional projects:** Cloner, Dark Descent, Elderwood v2, Forest of Gluttony, GunR (WebSocket), Hex, Tic-Tac-Toe, RPG, Testing, Yorg

**Technologies:** HTML, CSS, Canvas 2D API, vanilla JavaScript, Node.js (some)
