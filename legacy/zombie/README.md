# Zombie Survival Game

**Status:** Active

A 2D top-down zombie survival shooter. Move with WASD, aim with the mouse, and auto-fire at zombies by holding the left mouse button.

**Features:**
- Five weapons: AK-47, SMG, Pistol, Sniper, and "Death" god weapon — each with unique stats (magazine size, damage, fire rate, reload time)
- Auto-fire on mouse hold
- Zombie AI that chases the player
- Health-based colour change on zombies
- Bullet penetration system
- Game-over on zombie-player collision

**Technologies:** HTML, CSS, Canvas 2D API, vanilla JavaScript
