# Mini Browser-Based Code Editor

A browser-based code editor with a file explorer sidebar, tabbed editing interface, and JSZip-based ZIP export. Create, rename, and delete files, then download the whole project as an archive.

**Features:**
- File explorer with right-click context menu
- Tabbed interface with close buttons
- ZIP export via JSZip

**Technologies:** HTML, CSS, vanilla JavaScript, JSZip (CDN)
