⚠ Running on GitHub Pages
✕
This chat needs the Gemini backend, which Pages can't run — the request would return a 405. Download this folder and run it locally:
  1. Open the folder, then run npm install
  2. Create a .env file with your key: GEMINI_API_KEY=your_key_here
  3. Start it with npm start
  4. Open http://localhost:3000
