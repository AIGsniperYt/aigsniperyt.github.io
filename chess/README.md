# **MAJOR** — Kaiser: Chess Engine

A full chess implementation with significant potential for further development (AI, UCI, etc.).

A full chess game implementation with board rendering, move validation, check detection, castling, en passant, and move history tracking.

**Features:**
- Complete chess rules including castling and check detection
- Tracks controlled squares for both sides
- Move history recording
- v2 includes obfuscation and npm build pipeline

**Technologies:** HTML, Canvas 2D API, vanilla JavaScript (v1), Node.js (v2)
